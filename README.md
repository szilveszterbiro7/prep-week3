# **Unit converter**





A simple console-based unit converter written in C++. Pick a category, choose the units to convert from and to, enter a value, and get the result.

### **How to run**

Open the Releases page.

Download UnitConverter.exe from the latest release.

Follow the on-screen menu to select a conversion category.

Choose the units you want to convert, enter a value, and view the result.

Follow the menu options to perform another conversion or exit the application.

### **Features**



* 7 conversion categories with a menu-driven interface.
* Input validation for menu and unit choices.
* Results shown to 4 decimal places.
* Option to return to the main menu after each conversion.



#### **Supported Conversions**

&#x09;

|**Category**|**Units**|
|-|-|
|Distance|Millimeter, Centimeter, Decimeter, Meter, Inch, Foot, Yard|
|Temperature|Celsius, Fahrenheit, Kelvin, Rankine|
|Weight|Milligram, Gram, Kilogram, Ton, Pound, Ounce, Carat|
|Speed|Meters per second, Kilometers per hour, Miles per hour, Feet per second, Knots|
|Volume|Cubic meter, Cubic centimeter, Cubic decimeter, Liter, Milliliter, Gallon, Fluid ounce|
|Area|Square meter, Square kilometer, Square inch, Square foot, Are, Hectare, Acre|
|Time|Millisecond, Second, Minute, Hour, Day, Week, Fortnight|





#### **How It Works**



Each category converts the input to a base unit (for example, millimeters for distance), then converts from the base unit to the target unit. Temperature uses its own formulas, with Celsius as the base.
